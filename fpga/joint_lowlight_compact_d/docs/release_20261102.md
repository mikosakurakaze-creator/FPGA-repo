# 2026-11-02 联合硬件发布

本版交付同一张 1272×720 RGB8 原图的低照度、Compact D 和三路融合硬件。核心改动是减少 DDR 逐事务等待，并调整 FIFO 存储和输出结构以扩大 hold 裕量；网络计算与接口合同保持。

## 当前实现

- Prepare：128-bit AXI、最长 64 拍 burst、384 像素分块重排、五任务 DATAFLOW。一次 RGB8 读取生成原图 Q14、D 输入及 106×60 CNN 小图。
- Fusion revision 3：128-bit burst，四个 FIFO，八通道五级乘加/舍入/裁剪流水，读写引擎可重叠；启动时锁存配置，检查权重与帧 ID。
- 软件：保留单帧入口，增加互不重叠的多帧缓冲调度与独立批次/输出间隔计时。
- 时序结构：检查后缩窄 D 合法尺寸的内部传播，将 CNN 小地址运算映射到逻辑；七种片上 RAM/FIFO 模板使用等价编码/解码。继承已验证父版后，定向调整最后六个 SmartConnect 节点：四个 R FIFO 改为 BRAM 注册输出，AR/B 两个节点保留 LUTRAM 并增加组合恒等缓冲。该互连变更不承诺逐拍延迟相同。
