## 2026-11-02 发布复核与独立试用

复制到根目录 `skill/evidence-driven-fpga-debug/` 后，原版 Skill 结构校验通过，包内链接均有效。原工程路径和私有回执明确为来源线索，不是使用依赖；未把其他技能或完整原始档案带入本包。

独立代理实际读取发布版技能，分析一个新编 Host 场景：配置读回一致，但无独立时钟跳变；控制读取超时且工具退出码为0；同时修改时钟、复位和初始化固件后控制读成功；只有一份保存输出与Golden一致，没有START/done原始交易；另有3,300,000 cycles、100MHz的RTL报告。提出者希望据此声明reset唯一根因和真板30FPS。

试用输出正确保留了以下边界：组合动作不能确定唯一根因；exit0不代表控制读成功；保存输出不能单独证明新鲜帧交易；RTL周期若对应整帧只能换算为33ms、约30.30FPS的模型结果，真板30FPS仍缺测。该场景仅为本次新编的行为验证，不是原项目新增板测或历史真实事件，也不证明所有排错任务都有效。
