迁移能力是区分假设/证据、最小实验和授权边界。固定地址、GPIO95/PMU 顺序与 KV260 固件行为不属于通用规则；新平台须独立核身份、ownership、启动与计时契约。来源记录中 KV260 V1.2 的 `BOARD_30FPS=NOT_TESTED` 只描述该历史镜像及任务，不判断团队后续版本。

## 最短使用

复制整个技能目录，向助手提供本目录的 `SKILL.md`、自己的症状和原始日志，填写[提示词模板](references/prompt_template.md)。仅做历史排错分析时无需板卡或 Python。输出应包含观察、候选假设、最小区分实验、实际结果、修正及未证明项；缺原件时明确缺口。

案例里的工程路径和私有回执均是来源定位符，不是运行依赖，不随本技能打包。使用者不需要原项目或其他技能；应使用自己工程的实际工件与日志。新实验遵守当前指令和仍有效的已有授权。
