# V1 范围

## 目标

建立单模型低照度增强从软件参考到 FPGA 板端单张图像处理的完整工程流程，并形成可供团队并行开发的接口基线。

## V1 任务

1. **模型纯软件复现**：确定轻量化低照度增强模型，建立输入输出规范和软件参考结果。
2. **上板前准备**：完成模型导出、量化/定点化方案、权重转换与逐层数值校验。
3. **FPGA 实现**：设计 HLS 计算核，进行后续仿真、综合、接口封装和 Vivado 系统集成。
4. **板端控制**：完成 Overlay/IP 加载、寄存器配置、数据传输和单张图像增强调用。
5. **测试、优化与 Base 对比**：比较软件、量化和硬件结果，记录延迟、帧率与资源利用率并迭代优化。

本次初始化仅创建上述工作区及文档，不实现具体模型、训练、推理或 FPGA 加速器。

## 暂不实现

- 雨天增强与去雨模型
- 雾天增强与去雾模型
- 多模型协同
- 退化类型识别及自适应策略控制
- 完整视频实时处理链路
- 数据集下载、模型训练及权重下载
- HLS 仿真/综合与 Vivado 构建
