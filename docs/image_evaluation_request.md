# 整图画质评测所需材料

A 组交付含 Golden 裁剪图和合成集成输入，不含正式画质报告所需的完整成对图像集。开展评测前，需通过项目约定渠道补齐以下材料。

## 输入样本

- 去雨：软件结果所使用的原始 Rain100L 雨图/清晰图配对，或明确标识的代表性最小测试子集。
- 去雾：软件结果所使用的 O-HAZE 雾图/清晰图配对，或明确标识的代表性最小测试子集。
- 部署评审所需的真实视频或摄像头帧，附原始尺寸和帧率。

每个文件需保留原文件名、颜色顺序、位深和无损源字节。计算哈希前不要缩放、重新压缩或隐式转换样本。成对画质评测要求退化输入与清晰参考具有相同裁剪范围和几何尺寸。

## 元数据

清单应包含相对样本 ID、输入路径、可用时的参考路径、宽、高、通道数、颜色空间、数据划分来源及每个文件的 SHA-256。说明样本来自训练、验证、测试、部署最小测试还是此前未见数据集。

## 需保留的输出

评测应保存原始输入、Q14 输入、原始 Q14 输出、预览图、参考图、逐图 PSNR/SSIM 和运行清单。真板测试还需记录 IP ZIP 或 bitstream 身份、tile 几何配置、计算时间、数据收集/回写时间、端到端时间、帧 ID 和丢帧数。数值核查以原始 Q14 输出为准，PNG 预览只用于目视检查。

不能将现有 A 组证据描述成完整数据集得分：所给去雨 Golden 是 Rain100L-001 的一张 96x96 裁剪图，去雾 Golden 是 38_outdoor 的一张 96x96 裁剪图。样本及其哈希未补齐前，不能声称已完成整图画质报告。
