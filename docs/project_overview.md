# 项目概述

## 背景与目标

夜间、雨天和雾天等复杂环境会降低道路监控画面的亮度、对比度和可辨识度。本项目计划使用轻量化深度学习模型分析视觉退化特征，选择合适的增强方式，并结合针对性的图像恢复算法改善视频质量。

V1 仅研究单模型低照度增强，以单张图像处理链路为起点。雨天、雾天、多模型协同和自适应策略将在后续阶段评估。

## 深度学习与 FPGA 的作用

深度学习模型提供图像增强算法及软件参考结果。部署阶段将评估模型量化和定点化，在可接受的精度损失下减少计算与存储需求。FPGA 侧计划利用并行计算、流水线和片上数据复用，提高嵌入式场景下的处理效率。

## PS/PL 协同初步思路

暂定平台为 PYNQ-Z2（Zynq-7000 XC7Z020）。初步划分如下：

- PS（Processing System）负责图像输入、预处理、硬件 IP 配置、数据搬运、结果读取和运行日志。
- PL（Programmable Logic）负责适合硬件并行化的低照度增强计算核。
- PS 与 PL 之间的数据通道、控制总线、缓存策略、位宽和地址映射均为 TBD，待模型及性能基线明确后确定。

该方案目前是工程规划，不代表相关软硬件功能已经实现，也不假设开发环境已安装完整的 Vitis HLS、Vivado 或 PYNQ 工具链。
