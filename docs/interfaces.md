# 模块接口约定

本文档定义 V1 团队间的初步交付边界。所有未确定参数统一标记为 **TBD**，不得用未经验证的值替代。

## model → deployment

| 交付项 | 初步约定 |
| --- | --- |
| 模型结构 | 提供可复现的模型定义、算子清单和版本说明；具体结构 TBD |
| 模型权重 | 提供版本、来源及校验信息；文件格式 TBD；大文件不直接提交 Git |
| 输入规范 | 图像尺寸、通道顺序、色彩空间、数值范围和归一化方式均为 TBD |
| 输出规范 | 输出尺寸、通道顺序、数值范围及后处理方式均为 TBD |
| 软件参考结果 | 提供固定样例的最终输出及必要的中间层输出，误差基准 TBD |

## deployment → fpga

| 交付项 | 初步约定 |
| --- | --- |
| 量化参数 | 提供逐层 scale、zero-point 或等价参数；量化方案 TBD |
| 定点格式 | 输入、权重、累加器和输出位宽及小数位均为 TBD |
| 权重文件 | 提供转换脚本、格式说明、层顺序与校验信息；布局 TBD |
| 逐层参考输出 | 提供固定输入对应的逐层张量、形状和误差容限；数据格式 TBD |

## fpga → board

| 交付项 | 初步约定 |
| --- | --- |
| 硬件 IP | 提供版本、功能、时钟/复位要求及可复现构建说明 |
| 控制寄存器 | 寄存器名称、偏移、位域、读写属性和启动/完成时序均为 TBD |
| 输入输出接口 | 总线类型、端口宽度、图像布局、步长、对齐和传输协议均为 TBD |
| 权重加载 | 加载位置、顺序、容量、生命周期及校验机制均为 TBD |

## board → evaluation

| 交付项 | 初步约定 |
| --- | --- |
| 增强结果 | 保存可追溯的输入、输出及对应软硬件版本信息 |
| 运行日志 | 记录配置、状态、异常和重复实验所需信息，格式 TBD |
| 延迟与帧率 | 说明计时边界、预热方式、样本数和统计方法 |
| 资源利用率 | 记录 LUT、FF、BRAM、DSP 等工具报告指标及构建版本 |

任何接口变更应先更新本文档，再由上下游共同确认并在各自分支实现。

## Zero-DCE++ V1 当前交付约定

Zero-DCE++ 官方源码、官方 `Epoch99.pth` 和软件适配代码已经纳入 `model/zero_dce_pp/`。推理、一致性验证和参考数据导出工具已经编写，但尚未实际运行验证；FPGA 实现尚未完成。

当前 `model → deployment` 的参考数据交付格式为：

- FP32 NumPy `.npy`，张量布局 NCHW，通道顺序 RGB；
- 预处理输入、下采样输入、低分辨率参数图和全分辨率参数图；
- 八次增强迭代结果和最终增强结果；
- `metadata.json` 中的模型来源、上游 Commit、权重 SHA-256、图片尺寸、`scale_factor`、PyTorch 版本、设备和 dtype。

PNG 仅作为人工查看用预览，不得作为数值参考。卷积层中间结果将在下一阶段补充。量化位宽、定点格式、舍入、饱和、硬件布局和允许误差仍为 TBD。
